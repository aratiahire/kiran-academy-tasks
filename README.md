# Task 01: Shopping Bill
Languages Used: Python 

# Description
A shopping bill program that calculates GST for electronics, fashion and food items, adds the amounts to calculate the total bill and applies a 20% discount to determine the final payable amount.

# GST Rates
* Electronics: 18%
* Fashion: 13%
* Food: 7%
* Discount: 20%

# Sample Values
All five item amounts are set to ₹100.

# Expected Output
Total after GST = 569.00
Discount = 113.80
Final payable amount = 455.20

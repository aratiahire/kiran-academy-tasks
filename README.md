# Python Programming Tasks
This repository contains my Python programming tasks and practice projects.

# Task 01: Shopping Bill
Description: A program that calculates GST on electronics, fashion and food items, then applies a 20% discount to the total bill.

Features:
* Calculate 18% GST on electronics.
* Calculate 13% GST on fashion.
* Calculate 7% GST on food.
* Calculate the total bill after GST.
* Apply a 20% discount.
* Calculate the final payable amount.

Sample Output:
Total after GST = 569.00
Discount = 113.80
Final payable amount = 455.20

File: shopping_bill.py

# Task 02: Hospital Billing Management
Description: A program that calculates hospital consultation fees, medicine costs, room charges, and the final payable amount after a discount.

Features:
* Calculate consultation fees.
* Calculate medicine costs.
* Calculate room charges based on the number of days.
* Calculate the total hospital bill.
* Apply a 10% discount.
* Calculate the final payable amount.

Sample Output:
Consultation Fee = 500.00
Medicine Cost = 1500.00
Room Charges = 3000.00
Total Bill = 5000.00
Discount = 500.00
Final Payable Amount = 4500.00

File: hospital_billing_management.py
